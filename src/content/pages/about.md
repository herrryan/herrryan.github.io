Hi, I'm **Ryan Guo** (Fei Guo) — a Cloud Architect and Systems Engineer passionate about distributed systems, resilient multi-cloud infrastructure, GraphRAG reasoning pipelines, and crafting native developer productivity tools.

## What I Do

### 1. Cloud Architecture & Enterprise Migrations
I design, automate, and orchestrate large-scale enterprise cloud transformations across Google Cloud (GCP), Microsoft Azure, and Amazon Web Services (AWS). My work focuses on:
- Declarative Infrastructure-as-Code (Terraform, OpenTofu, Terragrunt)
- Secure networking, multi-region failover, and zero-trust security postures
- Continuous integration, delivery pipelines, and gitops orchestration

### 2. AI Engineering & GraphRAG
I architect advanced information retrieval and reasoning architectures:
- Knowledge graph-augmented retrieval (GraphRAG) integrating Mem0 and Neo4j
- Multi-agent simulation environments and autonomous agent orchestration
- Low-latency vector database pipelines and LLM inference optimizations

### 3. Native macOS Developer Tooling
I build blazingly fast, native Apple Silicon-optimized macOS applications using Swift, AppKit, and SwiftUI:
- **TexSwift**: All-in-one LaTeX editor and compiler with sub-second Tectonic integration, PDFKit live preview, and CoreText typesetting.
- **SkimSwift**: Native PDF researcher and annotation reader with persistent document states and spotlight search.
- **MarkSwift**: Clean, distraction-free Markdown document editor with synchronous multi-window tab architecture.
- **NoteSwift & PicSwift**: Minimalist, keyboard-first desktop productivity utilities.
